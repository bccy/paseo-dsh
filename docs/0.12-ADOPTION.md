# Paseo 0.12 适配记录

> 分支 `feat/0.12-adoption`（基线 `84029dd`），本机 daemon/CLI 实测 `paseo --version` = 0.12.0。
> 本文只记 0.12 宿主契约带来的改动，安装/自举流程仍见 [ADOPTION.md](./ADOPTION.md)。

## 1. 版本对齐依据
- `@getpaseo/plugin@0.12.0` 的 `peerDependencies` 把 `@getpaseo/client`、`@getpaseo/protocol` 精确锁到 `0.12.0`（0.11.x 是精确锁 `0.11.2`）；devDep 写 `^0.11.2` 只会解析到 0.11.2，编译期类型与宿主实际契约不是同一份。
- 故 `paseo-plugin/package.json` 三个 devDep 由 `^0.11.2` 改为精确 `0.12.0`；`npm install` 后 `@getpaseo/{client,plugin,protocol,relay}` 全为 0.12.0（见 package-lock.json）。
- `paseo-plugin.json` 的 `requirements.paseo` 保持 `>=0.9.2`：只用协议层公开字段，未依赖 0.12 独有注册 API，不抬高下限。
- 审计依据：`~/.dsh/reviews/paseo-0.12-audit/` 的 `B-package-diff.md`（包级）、`C-plugins-matrix.md`（兼容）、`D-repo-adoption.md`（落点）。

## 2. 三个改动点

### 2.1 桥：识别 0.12 版本化 `paseo-system` 信封
- 现状：`dsh-bridge/lib/paseo-system-envelope.js:33` 只匹配 `^<paseo-system>\n[\s\S]*\n</paseo-system>$`；0.12 daemon 发带属性的 `<paseo-system version="1" kind="agent-message|agent-notification" source-agent-id="…" message-id="…" [event=… source-agent-title=…]>…</paseo-system>`，旧正则判不中 → `promptSource()` 把系统通知降级成 `{kind:"user"}`（当用户回合）。
- 改法：扩展识别并解析 kind/event/source-agent-id/message-id/source-agent-title；legacy 行为逐字不变、非 paseo 标签不误判。改 `dsh-bridge/` 后必须重跑 `node paseo-plugin/scripts/generate-bridge-assets.mjs` 重建内嵌桥。
- 验收：`node harness/paseo-system-envelope-check.mjs`（补 versioned/属性解析/反例）、`node harness/bridge-assets-check.mjs`。

### 2.2 客户端：`agent_message` 行语义
- 现状：0.12 把 agent 间消息投影成 `tool_call{name:"agent_message", detail:{type:"plain_text",…}}`；`paseo-plugin/client/tool-call-data.ts` 的 plain_text 分支读不到 label，行头退化成 `agent_message` + 原始 XML。
- 改法：入参加 type-only `agentMessage?`（类型取自 `@getpaseo/protocol@0.12.0`，不引入运行时依赖）；行头改「发送者 + 事件」（message/finished/errored/permission-required/closed 五类中英双语），正文用 `agentMessage.text`；字段缺失保持降级不抛错。
- 验收：新增 `node harness/agent-message-check.cjs`，更新 `node harness/tool-call-check.cjs`。

### 2.3 客户端：Paseo 工具标签/图标对齐官方 catalog
- 官方词表：`@getpaseo/protocol@0.12.0` 的 `PASEO_TOOL_CATALOG`（61 项）。
- 现状差异：`paseo-plugin/client/tool-call-data.ts` 的 `PASEO_MCP_ICONS` 缺 browser_back / browser_forward / browser_reload / browser_hover；`paseo-plugin/client/locale.ts` 部分英文标签与官方不一致。
- 改法：补齐图标；英文以官方为准，中文按官方语义重译（`speak` 保留既有例外）。
- 验收：`node harness/locale-check.cjs` 增「与官方 catalog 对比」断言。
